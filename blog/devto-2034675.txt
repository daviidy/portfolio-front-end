<span data-line=""><span style="--shiki-dark:#E1E4E8;--shiki-light:#24292E">  assetPrefix: isProd </span><span style="--shiki-dark:#F97583;--shiki-light:#D73A49">?</span><span style="--shiki-dark:#9ECBFF;--shiki-light:#032F62"> '/your-repository-name/'</span><span style="--shiki-dark:#F97583;--shiki-light:#D73A49"> :</span><span style="--shiki-dark:#9ECBFF;--shiki-light:#032F62"> ''</span><span style="--shiki-dark:#E1E4E8;--shiki-light:#24292E">,</span></span>

<p><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark github-light" style="--shiki-dark:#e1e4e8;--shiki-light:#24292e;--shiki-dark-bg:#24292e;--shiki-light-bg:#fff"><span data-line=""><span>isProd</span></span></code></span> checks if the NODE_ENV environment variable is set to 'production'. If it is, isProd will be true; otherwise, it will be false.
Conditional <a href="https://nextjs.org/docs/app/api-reference/next-config-js/assetPrefix">assetPrefix</a> and <a href="https://nextjs.org/docs/app/api-reference/next-config-js/basePath">basePath</a> are set to your repository name only if isProd is true. Otherwise, they are set to an empty string for local development.
The <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark github-light" style="--shiki-dark:#e1e4e8;--shiki-light:#24292e;--shiki-dark-bg:#24292e;--shiki-light-bg:#fff"><span data-line=""><span>images.unoptimized</span></span></code></span> option is set to true to disable the default image optimization, which is not compatible with static exports.</p>
<p><strong>Step 3: Update package.json</strong></p>
<p>Update your package.json to include the homepage field and the deploy scripts.</p>

<p><strong>Step 4: Deploy Your App</strong></p>
<p>Run <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark github-light" style="--shiki-dark:#e1e4e8;--shiki-light:#24292e;--shiki-dark-bg:#24292e;--shiki-light-bg:#fff"><span data-line=""><span>npm run predeploy</span></span></code></span> and <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark github-light" style="--shiki-dark:#e1e4e8;--shiki-light:#24292e;--shiki-dark-bg:#24292e;--shiki-light-bg:#fff"><span data-line=""><span>npm run deploy</span></span></code></span></p>
<p>These commands will:</p>
<ul>
<li>Build your project.</li>
<li>Export it to the out directory.</li>
<li>Deploy it to the gh-pages branch on GitHub.
Push your work to your GitHub branch before the next step</li>
</ul>
<p><strong>Step 5: Configure GitHub Pages</strong></p>
<p>Go to your repository on GitHub.
Navigate to Settings > Pages.
Under Source, select the gh-pages branch.
Save the settings.
Add manually the .nojekyll file at the root of the gh-pages branch on GitHub. Learn more about this <a href="https://github.com/vercel/next.js/discussions/33751">here</a>.</p>
<p><strong>Step 6: Verify Deployment</strong></p>
<p>After deploying, open your GitHub Pages URL (e.g., https://.github.io/) to verify that your app is live.</p>
<p>And voila!</p>
